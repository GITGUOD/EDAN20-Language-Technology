The course Language Technology at Lund University, also known as EDAN20, is one of the master’s level courses in Machine Intelligence. It provides students with both theoretical knowledge and practical skills in natural language processing (NLP). The course is divided into two main components: Statistical Techniques for Text Analysis (3.5 credits), which focuses on probabilistic models, language modelling, and corpus-based methods; and Syntactic and Semantic Text Processing (4.0 credits), which covers parsing, meaning representation, and advanced techniques for text understanding.
